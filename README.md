# 🧶 Ateliê da Vó Bela

Site e vitrine virtual para o **Ateliê da Vó Bela**, destacando peças artesanais de crochê feitas à mão com amor, carinho e fios nobres sob encomenda.

Visite a vitrine para conhecer peças de **Mesa Posta**, **Decoração & Sala** e **Cozinha & Banheiro**, com solicitação direta de orçamento sob medida via WhatsApp.

---

## ✨ Funcionalidades

- **Vitrine Interativa**: Catálogo categorizado com filtro rápido e barra de busca em tempo real.
- **Card de Produto com Especificações**: Altura e proporção padronizadas, tags de destaque e modal detalhado com orientações de lavagem e conservação.
- **Integração Dinâmica com WhatsApp**: Botão de orçamento nos cards e no modal com mensagem personalizada preenchida com o nome da peça.
- **Botão Flutuante de WhatsApp**: Acesso rápido ao contato oficial em qualquer rolagem da página.
- **Design Warm & Cozy**: Paleta terrosa artesanal (terracota, linho, verde sálvia e areia) construída com Tailwind CSS.
- **100% Responsivo**: Otimizado para celular, tablet e desktop.
- **SEO & Open Graph**: Cartões de compartilhamento automáticos com imagem e descrição para redes sociais e WhatsApp.

## 🚀 Como Executar Localmente

1. Clone o repositório:
   ```bash
   git clone https://github.com/SEU_USUARIO/atelie-da-vo-bela.git
   cd atelie-da-vo-bela
   ```

2. Instale as dependências:
   ```bash
   npm install
   ```

3. Inicie o servidor de desenvolvimento:
   ```bash
   npm run dev
   ```
   Acesse no seu navegador: `http://localhost:5173/`

4. Para gerar o build de produção:
   ```bash
   npm run build
   ```
